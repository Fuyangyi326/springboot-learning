# 学生管理系统

这是一个基于 Spring Boot 3.3 + Spring Data JPA + MySQL (H2) + 原生前端开发的完整全栈项目。

## 功能
- 学生信息的增删改查
- 统一响应格式与全局异常处理
- 现代化前端界面

## 技术栈
- Spring Boot
- Spring Data JPA
- H2 Database
- HTML / CSS / JavaScript
